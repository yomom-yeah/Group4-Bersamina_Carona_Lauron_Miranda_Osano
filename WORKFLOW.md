Team Collaboration Workflow



Our team uses Git and GitHub to work together on the project. We follow these steps so that everyone’s work is organized and updated.



1\. Branch



A branch is a separate place where we can work on our assigned task without changing the main project right away. Each member creates or uses their assigned branch before making changes.



2\. Commit



After finishing a change, we make a commit. A commit saves the changes we made and includes a short message explaining what we did. This helps the team keep track of the work.



3\. Push



After committing our work, we push the branch to GitHub. This uploads our changes from the computer to the online repository so the other team members can see them.



4\. Review



After pushing the branch, we create a pull request. The assigned reviewer checks the changes to make sure they are correct and complete. If there is a problem, the reviewer can leave a comment so it can be fixed before merging.



5\. Merge



Once the pull request has been reviewed and approved, it can be merged into the main branch. This adds the completed work to the main version of our team project.



6\. Synchronization



After a pull request is merged, every team member updates their local main branch. This makes sure everyone has the latest version of the project before starting another task.
